## How I Engineer

- **AI where it adds value:** I consider whether a problem actually needs AI before introducing model complexity.
- **Deterministic where it matters:** AI proposes, deterministic code verifies, and humans approve anything risky.
- **Designed for failure:** I build around retries, recovery, checkpoints, validation and observable execution.
- **Measured by outcomes:** I care about accuracy, reliability, latency, cost and the actual business problem being solved.
- **Ownership beyond implementation:** I take products from understanding the problem through architecture, development, deployment and continuous improvement.
